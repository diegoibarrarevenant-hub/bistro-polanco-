# Campaña de Redes Sociales — VoltaG

Campaña integral de crecimiento de seguidores para la banda **VoltaG** (Facebook: 618 seguidores → Meta: 3,000+ en 90 días).

## Estructura del Proyecto

```
campana-voltag/
├── estrategia/
│   ├── analisis-cliente.md      # Diagnóstico y situación actual
│   ├── audiencia-objetivo.md    # Segmentos y targeting
│   └── plan-90-dias.md          # Plan de acción por fases
├── contenido/
│   └── calendario-contenido.md  # Pilares, calendario semanal, hooks y hashtags
├── anuncios/
│   └── copies-anuncios.md       # Copies para las 3 campañas pagadas
└── metricas/
    └── dashboard-kpis.md        # KPIs, benchmarks y plantilla de reporte
```

## Resumen de la Campaña

| | |
|---|---|
| **Cliente** | VoltaG — Banda de música en vivo |
| **Plataformas** | Facebook (principal), Instagram, TikTok |
| **Duración** | 90 días (3 meses) |
| **Presupuesto pauta** | $27,400 MXN (~$1,370 USD) |
| **Meta de seguidores** | 3,000 Facebook / 1,000 Instagram / 1,000 TikTok |

## Fases

1. **Semanas 1–2:** Optimización de perfil + Campaña Me Gusta
2. **Semanas 3–6:** Contenido viral + Campaña de Alcance de Video
3. **Semanas 7–12:** Comunidad activa + Campaña de Contratación
